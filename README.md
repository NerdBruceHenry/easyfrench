# 🥐 EasyFrench · 从零到 B2

一个为**有英语基础（B2–C1）的中文学习者**设计的系统化法语学习工具。纯前端网页，无需安装、无需注册，打开浏览器就能用，手机电脑都适配。

> 核心思路：英语里约 30%–45% 的词汇来自法语，很多语法结构（完成时、被动、条件句、关系从句）也相通。本工具在每个知识点上都**拿英语做对比**，帮你把已有的英语能力「迁移」到法语上，同时专门提示英语使用者最容易踩的坑（假朋友、阴阳性、介词、虚拟式等）。

## 🚀 使用方法

### 方式一：GitHub Pages（推荐，手机也能用）

1. 把代码合并到 `main` 分支
2. 打开仓库 **Settings → Pages**，在 **Build and deployment → Source** 选择 **GitHub Actions**
3. 等待 Actions 跑完，访问 `https://justinlee1319.github.io/easyfrench/`
4. 手机上用浏览器「添加到主屏幕」，就像一个 App

### 方式二：本地打开

直接双击 `index.html` 即可（语音识别在 `file://` 下可能不可用）。或者：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000

### 浏览器建议

- **Chrome / Edge**：全部功能可用（包括语音识别评分）
- **Safari**：朗读可用，语音识别取决于系统版本
- **Firefox**：朗读可用，不支持语音识别（可用「录音回放」自评）
- 朗读用的是系统自带的法语语音。如果声音机械，可以在系统设置里安装更好的法语语音（macOS：Amélie / Thomas 增强版；Windows：Microsoft Denise / Henri Natural）

学习进度保存在浏览器本地（localStorage）。换设备前请在「设置」里**导出备份**。

## 📅 推荐学习路线（每天 30–60 分钟）

| 阶段 | 时长（约） | 在本工具里 | 工具之外 |
|---|---|---|---|
| **A1** | 第 1–3 个月 | 每 1–2 天学一个单元；每天复习卡片；发音课全部学完 | 听法语歌，看带字幕的 Easy French 街头采访 |
| **A2** | 第 4–6 个月 | 单元 + 每天听写 5 句 + 跟读；每周一篇写作 | TV5Monde Apprendre；开始找语伴 |
| **B1** | 第 7–12 个月 | 单元 + 阅读 + 情景对话；写作用 AI 批改 | 每天听 RFI Journal en français facile；InnerFrench 播客 |
| **B2** | 第 13–20 个月 | 单元 + 议论文写作 + DELF 口语模拟 | 看法剧/法国电影（法语字幕）、读 1jour1actu / Le Monde；做 DELF B2 真题 |

**每天的标准流程（首页「今日计划」会自动安排）：**
1. 🔁 复习到期卡片（5–10 分钟）
2. 📘 学习新单元或复习旧单元（15–20 分钟）
3. 🎧 听写 5 句 + 🗣️ 跟读 5 句（10 分钟）
4. 📖 阅读或 ✍️ 写作（交替进行）
5. 🎮 一局小游戏收尾

> ⚠️ 说实话：任何单一工具都不能单独把你带到 B2。本工具提供**系统化的骨架**（词汇、语法、四项技能的刻意练习）；要真正达到 B2，从 A2 开始还需要每天 20–30 分钟的**真实法语输入**（播客、视频、文章）和**真人口语练习**。「沉浸资源」页面列出了推荐资源。

## ➕ 如何添加内容

所有内容都是普通的 JS 数据，直接编辑即可：

- **新单元**：在 `js/data/*.js` 里按现有格式 `EF.units.push({...})`。词汇格式 `['la maison', 'house', '可选提示']`，以 `l'` 开头的名词请标注 `(m.)` 或 `(f.)`。
- **新文章**：在 `js/data/readings.js` 添加，`gloss` 是文中词形的释义。
- **新写作任务**：在 `js/data/practice.js` 添加，`checks` 用正则检查要求（已支持法语重音字母）。

没有任何构建步骤和第三方依赖。
